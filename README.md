# 绿荫森林 · 3D 校园规划 Demo

在线演示：[https://green.qdfb.tech/](https://green.qdfb.tech/)（阿里云，2026-11-15 发布 0.8.0）。选择「综合路线 · 分段搭配」，即可按位置分段并分别选择绿植、遮阳网、PC 板连廊或完整走廊；全部共用一个总预算。

本地校园遮阳改造规划演示：导入校园图片、校准比例、点击起终点，输入净宽和总预算，生成预算内的分期概念方案、材料估算与安装资料入口。可切换 3D 规划和第一人称漫游，并自由放置计划栽植的树木。

3D 规划：拖动旋转、滚轮缩放、Shift 拖动平移。漫游：WASD 或方向键走动、拖动转头，空格跳跃，快速双击空格切换飞行；飞行时按住空格升高、Shift 降低，再双击空格结束飞行并落下。也可按画面中的方向、跳跃和飞行按钮；Esc 返回规划。场景上方直接点「种树」，点击空地放置绿植；漫游时视角会轻微向下，拖动只转动视角。室外放乔木、室内放盆栽，点「撤销绿植」撤销。种树只需要有效预算和单价，不要求先完成路线。示例树价为 380 元/棵，可编辑；种树费用先占用预算，剩余部分分配给遮阳建设。降低预算后买不起的树显示为橙色待建，不计作已建设。

运行：`npm start`，打开 http://127.0.0.1:4196/ 。macOS 也可运行 `bash 启动绿荫森林.command`；从 GitHub 下载后，如需双击启动，先执行 `chmod +x 启动绿荫森林.command`。测试：`npm test`；静态文件打包：`npm run build`。

## 自动部署到阿里云

将代码推送或合并到本仓库的 `main` 分支后，[GitHub Actions](https://github.com/loyee001/tianqi/actions) 自动运行测试、构建并打包；只有全部成功才更新 `production` 发布分支。服务器每 60 秒检查已构建的发布包，通过文件校验后切换至新版本。总耗时还包含 GitHub 排队、构建及网络传输时间。

线上地址为 [green.qdfb.tech](https://green.qdfb.tech/)，[version.json](https://green.qdfb.tech/version.json) 中的 `source_sha` 可用于核对当前上线的源码提交。测试或构建失败时不发布；服务器校验失败时保留当前版本，切换后的健康检查失败会恢复上一版本。普通功能分支和未合并的 PR 不会更新线上网站。

需要重跑时，可在 Actions 中打开部署工作流并选择 **Run workflow**（`main`）。`production` 由工作流维护，不要手工修改。服务器直接从 GitHub 官方服务下载静态发布包；本流程不使用服务器登录密钥、OSS 中转或服务器端仓库脚本执行。

3D 点「起点 → 终点」后，点两下地面自动完成；规划与漫游模式均可用，重复点和穿墙的直线会提示重选。平面图仍支持多点标注。取消重画会保留原路线。点击场景中的教学楼、图书馆、食堂、活动室快捷入口，或从门洞步行进入，可查看一楼示例内饰并继续规划。墙、玻璃、家具、楼顶、遮阳棚与支柱具有碰撞；棚底挡住上升，棚顶可着陆。

室内路线是地面通行指示，只计全校园已放置绿植与预备金，不采购户外棚架。室内与室外按独立路线规划。四馆内饰为单层演示布局，不是实际学校测绘结果。上传图片仍只作为底图，不能自动变成可进入的建筑。

## 已实现
- JPG / PNG / WebP 本地导入（10 MB），路径点标注、撤销、恢复示例。
- 真实 WebGL 3D 建筑体块、树木、顶棚与支柱；3D 与平面图切换。
- 示例图按比例自动测长；上传图可选两个点填写实际距离校准，也可填写整条路线的实测长度校准。
- 路线长度、路径点数、预算无业务上限；非数字、负值与真正的数值表示溢出分别处理。预算以整数分计算，大额金额使用精确文本显示。
- 四种方案：仅种绿植、完整走廊、透气遮阳网（不防雨）与 PC 板连廊。仅种绿植无需路线或路径尺寸，预算与导出均只计绿植和预备金。切换方案保留已放绿植与原路线。
- 完整走廊有独立实体屋面、较粗立柱、铺装、双侧排水与照明，并在材料清单分别计价；仍按预算资助整模块，待建段不参与碰撞或遮阴。
- 将总预算的一部分先预留，随后计算可负担的整模块数量；不足时显示分期范围。
- 覆盖材料、支撑、连接、基础施工、安装、测量复核、运输费用；可编辑示例单价。
- 导出带预算说明的 3D PNG、平面 SVG 概念设计图和 CSV 材料清单。
- 官方安装视频页面与 PDF 入口；PC 板未选择型号，明确显示资料待补齐。

## 演示边界
这是浏览器本地的规则计算 Demo，无模型 API、自动识图、自动规划避障或真实供应商报价。图片不离开浏览器，刷新后不保留。路线长度按校准比例计算，未校准的上传图片不会猜测真实距离。路径是手工标记的中心线，平面覆盖色带宽度不表示真实宽度。上传图仅用作 3D 底图，不会伪装成已重建校园建筑；示例校园的建筑高度、树冠和光照为演示。极端尺寸下 3D 可使用可见的示意比例，但预算和路径金额仍按输入计算。

所有价格均为演示值（假设全包费用），不是当前市场报价。6 m 为计价模块，每模块计4组支撑/连接/基础，仅用于演示工程量与预算约束，不构成结构规格。材料规格、损耗、税费、当地人工及现场附加工程须合并到真实报价后重算。预备金是预算预留，不是已发生费用。未验证实际降温、遮阴时段、消防、风荷载或结构安全，导出图不是施工图。

## 环境模拟与推荐度
页面使用独立、可复现的夏季微气候模拟，没有接传感器或实时天气。模拟太阳时从 12:00 开始，每实际 1 秒推进 1 分钟；可以暂停、拖动时间或切换晴天／云层变化／高温天。太阳按简化季节几何运动；云量采用连续的多尺度变化，辐照随太阳高度和云量改变；气温有约 55 分钟惯性，单分钟变化限制为 0.06°C，并在午后达到较高值。辐照单位 W/m²，不是照度 lux。3D 灯光与阴影随模拟太阳和光照更新。

每条已画室外路线都会显示 0–100% 规则推荐度。评分考虑示意暴晒比例、光照强度、温度需要、路线长度取舍和预算覆盖，已知建筑／树干碰撞会扣至零；预算覆盖不足一半时分数不超过49。低于50%显示“可行性过低，请换一条路线”，有合适候选时可直接换用。夜间或弱光不推荐新增遮阳。百分比不是成功概率、结构安全结论或实测降温预测。

候选路线可在预算内截取连续优先段，显示具体起终点、长度和金额。推荐只在卡片中更新，点击采用才改动现有路线；已有绿植和预备金仍计入预算。上传图只分析用户已标注路线，不会凭一张图片发明建筑或候选路径；未知建筑阴影按无遮挡处理并标注假设。室内方案不套用室外日晒评分。

绿植碰撞包含树干、树冠主要实体、盆栽花盆；未资助的待建绿植不阻挡行走。不能在墙、家具、已有树或玩家身体占用的位置重叠种植，失败位置明确提示“这里无法种树”并说明原因。

## 种植推荐与光照覆盖
页面的“本期建设”可直接切换“仅种绿植”和“完整走廊”。布置、撤销、调整预算后会立即重算每株绿植的推荐度、评分原因及室外阳光直射／遮阴覆盖率；太阳运动时覆盖率每模拟分钟重算一次。

覆盖率采用固定地面采样点，示例校园排除建筑占地。太阳位置与场景一致，树冠按两层不透光椭球投影近似；相交树阴取并集，不重复累计。“新增绿植增加遮阴”是对同一时刻、同一建筑／既有树／已建棚架基线的净增百分点。有室外路线时另列路线中心线的覆盖比例。室内盆栽、待建树和撤销树不参与室外遮阴，未校准图纸不猜测百分比。夜间直射比例为 0，遮阴率显示不适用，不把夜间变暗算作种树收益。

树木推荐度考虑当前模拟温度、辐照、原有遮阴、与其他新树的阴影重叠、单株独立贡献和预算；总体为各株规则评分平均值。室内盆栽只给预算已落实的布置基础分，并明确窗边光照、品种和养护信息未知。上传图未识别建筑与既有树，覆盖以整幅图为室外平地的假设计算并明确标注。这些百分比是概念模型的几何／规则结果，不是实测照度、降温效果或植物生长适宜性结论。

## 3D 光照范围与校园行人
3D 场景默认打开“光照范围”：金色为阳光直射，灰绿色为原有建筑／绿植／棚架遮阴，鲜绿色为新植树木额外增加的树荫。范围与覆盖百分比来自同一份地面采样，种植、撤销、预算变动后立即更新；太阳模拟每推进一分钟重新计算。场景旁的太阳时滑块和暂停按钮与环境面板同步。夜间不绘制直射／树荫覆盖色，图纸未校准时不猜测范围。范围着色贴在室外地面与铺装上，可关闭着色观察自然光影。

示例校园有沿已知道路活动的三维人形行人，带迈步、摆臂和服装变化。他们和玩家、建筑、已安排绿植、其他行人进行身体碰撞，停止时不原地迈步。其中 4 名行人分别从真实门洞进出教学楼、图书馆、食堂和活动室，其余在室外巡游；室内计数随进出更新。场景工具栏可开关“校园行人”。上传图尚无可验证的通行区域，因此不自动添加行人。

## 直线、折线与弧线
在地图工具栏选择路线形状后开始绘制。直线选择起点、终点即可完成；折线依次点击起点、各个转弯点和终点，最后点“完成标注”；弧线依次选起点、终点、希望经过的位置，第三次点击自动生成平滑曲线。规划和漫游均可操作。弧线按自适应采样累计真实弯曲长度，材料、预算、遮阴与推荐分析使用同一条曲线；超出图纸或实际曲线碰到已知实体时提示重选经过点，取消会恢复原路线。

## 综合路线与分段搭配

选择“综合路线 · 分段搭配”，或在地图工具条点击“分段搭配”。同一条直线、折线或弧线可以在图上点击分界，也可输入距起点的米数，逐段选择完整走廊、PC 板连廊、遮阳网或仅绿植；支持调整分界与并入前段。规划和漫游均可操作。

各建设段独立按 6 m 模块计量；同类材料的测量及进场费只计算一次，树木及预备金全局只计一次，按起点顺序资助。绿植段保留现有地面，实际种树另按株数计算，不能把绿植段长度算成棚架遮阴。3D、平面图、光照范围和 CSV 分段费用同步。
